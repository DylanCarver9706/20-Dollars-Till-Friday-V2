# $20 Till Friday

A web app designed to help users manage their finances by tracking recurring charges and providing insights into their financial position. The app aims to teach financial literacy and promote independence by helping users understand their spending patterns and calculate their disposable income.

## Features

- **Recurring Charges Management**: Users can manage and view their recurring debits and credits using an intuitive frontend interface.
- **Disposable Income Calculation**: Custom algorithms calculate disposable income, providing users with a clear view of their financial status.
- **Real Transaction Data Integration**: Utilizes the Plaid API to securely retrieve real transaction data.
- **Secure Data Storage**: Transaction data is stored in a NoSQL MongoDB database, served from a Python Flask API.

## Tech Stack

- **Frontend**: React
- **Backend**: Flask, MongoDB
- **API Integration**: Plaid API
